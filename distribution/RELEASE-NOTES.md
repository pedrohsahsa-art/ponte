## Ponte {VERSION} — build para testes

- Nova interface Classico XP no Windows e Android, com icones 3D originais feitos no Blender.
- Navegacao simplificada: Controlar, Arquivos e Conectar/Conexao; internet e DDNS em opcoes avancadas.
- Permissoes permanentes e parada/revogacao continuam explicitas, sem novas autorizacoes automaticas.
- APK Android assinado com a mesma identidade de desenvolvimento das builds anteriores.
- Windows x64 portatil com runtime .NET incluido. Extraia tudo e use **Iniciar Ponte.cmd**.
- Controle PC → Android com captura autorizada e gestos via Acessibilidade.
- Diagnosticos do controle no rodape do visualizador; Inicio/Voltar permitem sair do Ponte.
- Controle Android → PC, arquivos, audio do PC, monitores, qualidade adaptativa e internet direta IPv6.
- DuckDNS opcional, com token protegido no Windows; conta e configuracao nao estao incluidas.

Nenhum dado pessoal, certificado, pareamento, token ou chave privada de assinatura
acompanha os downloads. Cada usuario faz seu proprio pareamento.

Leia **LEIA-ME.txt** antes de usar. Os arquivos da biblioteca sao temporarios por
execucao Windows. Ha limitacoes de fabricante/app no controle Android. Esta nao
e uma versao de loja nem um produto com auditoria de seguranca independente.
